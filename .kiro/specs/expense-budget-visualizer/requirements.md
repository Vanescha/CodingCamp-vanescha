# Requirements — Expense & Budget Visualizer

## Tujuan
Membangun aplikasi web sederhana untuk mencatat pengeluaran harian, menampilkan daftar transaksi, menghitung total pengeluaran, dan memvisualisasikan distribusi pengeluaran berdasarkan kategori.

## MVP
1. Form input berisi:
   - Nama Barang
   - Jumlah
   - Kategori: Makanan, Transportasi, Hiburan
2. Semua kolom wajib diisi.
3. Transaksi baru tampil pada daftar transaksi.
4. Pengguna dapat menghapus transaksi.
5. Total balance diperbarui otomatis.
6. Grafik lingkaran diperbarui otomatis berdasarkan kategori.
7. Data disimpan menggunakan Local Storage.
8. Aplikasi responsif untuk perangkat mobile.

## Optional Challenges yang dipilih
1. Ringkasan bulanan.
2. Tombol mode gelap/terang.
3. Sorotan/struktur ringkasan kategori agar pengguna mudah melihat distribusi pengeluaran.

## Batasan teknis
- HTML, CSS, JavaScript murni.
- Tidak menggunakan React/Vue/framework frontend.
- Tidak membutuhkan backend.
- Hanya satu file CSS di `css/`.
- Hanya satu file JavaScript di `js/`.
- Chart.js digunakan hanya untuk grafik.
