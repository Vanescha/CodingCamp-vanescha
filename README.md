# Expense & Budget Visualizer

Aplikasi web untuk mencatat pengeluaran harian dan melihat distribusinya melalui grafik.

## Fitur
- Form Nama Barang, Jumlah, dan Kategori.
- Validasi input.
- Daftar transaksi yang dapat dihapus.
- Total balance otomatis.
- Grafik pie berdasarkan kategori.
- Local Storage.
- Responsif/mobile-friendly.
- Ringkasan bulanan.
- Mode gelap/terang.

## Menjalankan
Cukup buka `index.html` di browser modern. Internet diperlukan untuk memuat Chart.js dari CDN.

## GitHub Pages
1. Buat repository GitHub sesuai format:
   `CodingCamp-31August26-vanescha`
2. Upload seluruh isi folder proyek, termasuk `.kiro`.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan dan tunggu proses deployment.
